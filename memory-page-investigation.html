Stage 01 · Build a checkable example

Start with one program, by hand.

Before processing the files, I worked through the first request manually. A small example gives me a known answer to compare with the code. It also makes the distinction between useful data, unused space, and bookkeeping visible.

The values I started with

32,294 bits of useful data
The first entry in day_01/loads.

1,000-bit pages
A simple trial size.

64 bits per page
One bookkeeping record for each allocated page.

What I needed to check
The program must receive enough whole pages. I must count both kinds of extra memory, and I must not count the useful data itself as a penalty.

Find the number of pages

32,294 ÷ 1,000 = 32.294 → 33

Round up: 32 pages hold only 32,000 bits, which would not fit the request.

Calculate allocated space

33 × 1,000 = 33,000 bits

A partly filled page still occupies its full size.

Find the unused space

33,000 − 32,294 = 706 bits

The first 32 pages are full. This is the final page:

294 bits
used706 bits
unused
Page 33 · Total capacity: 1,000 bits

Add bookkeeping

33 × 64 = 2,112 bits

The records live separately. They need no additional pages or records.

Calculate the penalty

706 + 2,112 = 2,818 bits

Penalty = unused space + bookkeeping.

Next decision: code this same example in Rust and check that the answer is 2,818 bits.

Stage 02 · Check the implementation

Make Rust reproduce the hand calculation.

I first ran the starter “Hello, world!” program to confirm that the Rust project worked. Then I replaced it with the calculation for the same single request.

The calculation in code

let data_bits: u64 = 32_294;
let page_size: u64 = 1_000;
let pages = data_bits.div_ceil(page_size);
let unused = pages * page_size - data_bits;
let bookkeeping = pages * 64;
let penalty = unused + bookkeeping;

div_ceil divides and rounds up. Integer arithmetic keeps these costs exact.

Expected and observed output matched

Pages: 33
Unused space: 706 bits
Bookkeeping: 2112 bits
Total penalty: 2818 bits

This agreement supports the calculation for this example. It is a useful check before reading the data, though it does not prove every part of the program is correct.

Version 2 — Check the hand calculation for one program

This is the complete version used to reproduce 33 pages, 706 unused bits, 2,112 bookkeeping bits, and a 2,818-bit penalty.

File: memory-pages/src/main.rs · Run: cargo run

fn main() {
   let data_bits: u64 = 32_294;
   let page_size: u64 = 1_000;
   // Round up: allocate enough whole pages.
   let pages = data_bits.div_ceil(page_size);
   let allocated_bits = pages * page_size;
   let unused_bits = allocated_bits - data_bits;
   let bookkeeping_bits = pages * 64;
   let penalty = unused_bits + bookkeeping_bits;
   println!("Pages: {pages}");
   println!("Unused space: {unused_bits} bits");
   println!("Bookkeeping: {bookkeeping_bits} bits");
   println!("Total penalty: {penalty} bits");
}

Version 3 — Read day 1 and total its program penalties

This version reads every request in day_01/loads, counts the programs, and adds the two memory costs for 1,000-bit pages.

File: memory-pages/src/main.rs · Run: cargo run

use std::fs;

fn main() {
   let page_size: u64 = 1_000;
   // ".." goes up from memory-pages to its parent folder.
   let contents = fs::read_to_string("../workloads/day_01/loads")
       .expect("Could not read the day_01 loads file");
   let mut program_count: u64 = 0;
   let mut total_unused: u64 = 0;
   let mut total_bookkeeping: u64 = 0;
   for line in contents.lines() {
       let data_bits: u64 = line.trim().parse()
           .expect("Each line must contain a positive whole number");
       assert!(data_bits > 0, "Memory requests must be positive");
       let pages = data_bits.div_ceil(page_size);
       let unused_bits = pages * page_size - data_bits;
       let bookkeeping_bits = pages * 64;
       program_count += 1;
       total_unused += unused_bits;
       total_bookkeeping += bookkeeping_bits;
   }
   let daily_penalty = total_unused + total_bookkeeping;
   println!("Day: 01");
   println!("Page size: {page_size} bits");
   println!("Programs: {program_count}");
   println!("Unused space: {total_unused} bits");
   println!("Bookkeeping: {total_bookkeeping} bits");
   println!("Daily penalty: {daily_penalty} bits");
}
Version 4 — Evaluate all 32 days with 1,000-bit pages

The outer loop visits all 32 days. Each day starts with fresh totals, and the final average divides the sum of daily penalties by 32. This produced 68,853,587.46875 bits per day.

File: memory-pages/src/main.rs · Run: cargo run

use std::fs;

fn main() {
   let page_size: u64 = 1_000;
   let mut overall_penalty: u64 = 0;
   let mut total_programs: u64 = 0;
   for day in 1..=32 {
       let path = format!("../workloads/day_{day:02}/loads");
       let contents = fs::read_to_string(&path)
           .unwrap_or_else(|error| panic!("Could not read {path}: {error}"));
       let mut program_count: u64 = 0;
       let mut total_unused: u64 = 0;
       let mut total_bookkeeping: u64 = 0;
       for line in contents.lines() {
           let data_bits: u64 = line.trim().parse()
               .expect("Each line must contain a positive whole number");
           assert!(data_bits > 0, "Memory requests must be positive");
           let pages = data_bits.div_ceil(page_size);
           total_unused += pages * page_size - data_bits;
           total_bookkeeping += pages * 64;
           program_count += 1;
       }
       assert_eq!(program_count, 128, "Expected 128 programs on day {day}");
       let daily_penalty = total_unused + total_bookkeeping;
       overall_penalty += daily_penalty;
       total_programs += program_count;
       println!(
           "Day {day:02}: programs={program_count}, \
            bookkeeping={total_bookkeeping}, unused={total_unused}, \
            penalty={daily_penalty} bits"
       );
   }
   let average_penalty = overall_penalty as f64 / 32.0;
   println!("\nPage size: {page_size} bits");
   println!("Total programs: {total_programs}");
   println!("Sum of daily penalties: {overall_penalty} bits");
   println!("Average daily penalty: {average_penalty:.5} bits");
}

Stage 04 · Explore the trade-off

Try a few sizes and follow the evidence.

I changed the page-size value, saved the file, and reran the program. These tests were exploratory: they helped identify promising choices, but were not enough to prove an optimum.

How the results changed the next test

10,000 bits improved substantially on 1,000. But increasing to 100,000 made the penalty rise. I then tested 30,000, between those two choices, and obtained the best result of the four trials.

This showed why “make pages larger” was not a complete solution: fewer records can come with more unused space.

Next question: was there a better size between the values I happened to try? Testing only a few sizes could miss it.

Stage 05 · Replace guessing with a systematic search

Test every integer from 1 to 100,000.

I read all 4,096 requests once, then looped through every whole-number page size in the range. For each size, I added the same program penalties across all requests.

Keep comparisons exact

I compared integer totals, not rounded averages. Every total is divided by the same 32, so minimizing the total also minimizes the average daily score.

The code kept a list of equally good sizes. A new lower total cleared the list; an equal total added another size.

I used cargo run --release to run an optimized build for the larger search.

The limit of this result: the initial 100,000-bit cutoff was an exploratory boundary. Searching that range alone did not justify claiming the best size among all positive integers.
Version 8 — Search every integer page size from 1 to 100,000

This is the search version used to find [32768]. It reads the workload once, compares exact integer totals, and retains all sizes tied for the minimum.

File: memory-pages/src/main.rs · Run: cargo run --release

use std::fs;

fn main() {
   // Read the data once, before testing page sizes.
   let mut requests: Vec<u64> = Vec::new();
   for day in 1..=32 {
       let path = format!("../workloads/day_{day:02}/loads");
       let contents = fs::read_to_string(&path)
           .unwrap_or_else(|error| panic!("Could not read {path}: {error}"));
       let mut count = 0;
       for line in contents.lines() {
           let bits: u64 = line.trim().parse()
               .expect("Expected a positive whole number");
           assert!(bits > 0);
           requests.push(bits);
           count += 1;
       }
       assert_eq!(count, 128, "Expected 128 programs on day {day}");
   }
   let mut best_total = u64::MAX;
   let mut best_sizes = Vec::new();
   // Test every integer size in this range.
   for page_size in 1_u64..=100_000 {
       let mut total_penalty: u64 = 0;
       for &bits in &requests {
           let pages = bits.div_ceil(page_size);
           let unused = pages * page_size - bits;
           total_penalty += unused + pages * 64;
       }
       if total_penalty < best_total {
           best_total = total_penalty;
           best_sizes.clear();
           best_sizes.push(page_size);
       } else if total_penalty == best_total {
           best_sizes.push(page_size);
       }
   }
   println!("Search range: 1 to 100000 bits, inclusive");
   println!("Total programs: {}", requests.len());
   println!("Best page sizes in this range: {best_sizes:?} bits");
   println!("Sum of daily penalties: {best_total} bits");
   println!(
       "Average daily penalty: {:.5} bits",
       best_total as f64 / 32.0
   );
}

Next decision: find a lower bound for every size above 100,000, rather than choosing another arbitrary stopping point.

Stage 06 · Resolve the search limit

Could an even larger size win?

For any page size above 100,000 bits, the smallest possible size is 100,001. Every program needs at least one page and therefore at least one 64-bit record.

A deliberately generous minimum cost

If a request needs fewer than 100,001 bits, its page must leave at least 100001 − requested_bits unused bits. For a larger request, I use zero as a safe lower bound on unused space. I count just one record per program, even if it would actually require more.

Minimum per program = max(100,001 − request, 0) + 64

For example, a 1,000-bit request must waste at least 99,001 bits at these larger sizes, plus at least 64 bits of bookkeeping. Adding the lower bounds for all requests gives:

Lower bound above 100000 bits: 172260831
Best tested total:             101545439

172,260,831 > 101,545,439. Even this underestimate is worse than the best tested total. The actual total for any larger size must be at least as high as the bound, so every size above 100,000 is ruled out.

Conclusion: the search tested every positive integer up to 100,000 and found a unique minimum at 32,768. The bound rules out every larger integer. Together, they establish 32,768 bits as the unique optimal page size for these workloads and this memory model.

Final reporting version — search, lower-bound check, and daily costs at the winning size 
use std::fs;

fn main() {
    let mut days: Vec<Vec<u64>> = Vec::new();
    for day in 1..=32 {
        let path = format!("../workloads/day_{day:02}/loads");
        let contents = fs::read_to_string(&path)
            .unwrap_or_else(|e| panic!("Could not read {path}: {e}"));
        let requests: Vec<u64> = contents.lines().map(|line| {
            let bits: u64 = line.trim().parse().expect("Expected a whole number");
            assert!(bits > 0);
            bits
        }).collect();
        assert_eq!(requests.len(), 128, "Expected 128 programs on day {day}");
        days.push(requests);
    }

    let mut best_total = u64::MAX;
    let mut best_sizes = Vec::new();
    for page_size in 1_u64..=100_000 {
        let total: u64 = days.iter().flatten().map(|&bits| {
            let pages = bits.div_ceil(page_size);
            pages * page_size - bits + pages * 64
        }).sum();
        if total < best_total {
            best_total = total;
            best_sizes.clear();
            best_sizes.push(page_size);
        } else if total == best_total {
            best_sizes.push(page_size);
        }
    }

    let lower_bound: u64 = days.iter().flatten()
        .map(|&bits| 100_001_u64.saturating_sub(bits) + 64).sum();
    println!("Best page sizes: {best_sizes:?} bits");
    println!("Total penalty: {best_total} bits");
    println!("Average daily penalty: {:.5} bits", best_total as f64 / 32.0);
    println!("Lower bound above 100000 bits: {lower_bound}");
    assert!(lower_bound > best_total);

    // Report each winning size; retain all ties if there are any.
    for page_size in best_sizes {
        println!("\nDaily report for {page_size}-bit pages:");
        println!("day,programs,bookkeeping_bits,unused_bits,penalty_bits");
        for (index, requests) in days.iter().enumerate() {
            let mut bookkeeping = 0_u64;
            let mut unused = 0_u64;
            for &bits in requests {
                let pages = bits.div_ceil(page_size);
                bookkeeping += pages * 64;
                unused += pages * page_size - bits;
            }
            println!("{:02},{},{},{},{}", index + 1, requests.len(),
                bookkeeping, unused, bookkeeping + unused);
        }
    }
}
